## How to install (No Apple developer programs available)

- Clone repository
- Open in Xcode (install iOS support)
- Set your self as developer in `target` (in Xcode)
- Connect your iPhone
- Build (cmd + r)
- Then you have it
- Every 7 days - repeat ( or support please :) )
